# Sculk Sight

Sculk Sight is a client-side Minecraft mod that visualises where vibrations can reach sculk detectors. This wiki covers the current release, installation, and launch troubleshooting.

**Current release:** [v0.2.0 pre-release](https://github.com/scr0ols/Sculk-Sight/releases/tag/v0.2.0) for **Minecraft 26.2**, available for Fabric and NeoForge.

- [About](About) — what the mod does and where to find the project.
- [Installation](Installation) — requirements and downloads for each loader.
- [Troubleshooting](Troubleshooting) — installation and launch issues.

This wiki is a work in progress. For the full change list, see the [v0.2.0 release notes](https://github.com/scr0ols/Sculk-Sight/releases/tag/v0.2.0).
