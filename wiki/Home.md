# Sculk Sight

Sculk Sight is a client-side Minecraft mod that helps players understand where sculk detectors can receive vibrations. This wiki covers the released installation and project basics; it is still being built out while the mod is in development.

**Current documented release:** [v0.2.0 pre-release](https://github.com/scr0ols/Sculk-Sight/releases/tag/v0.2.0) for **Minecraft 26.2**, available for Fabric and NeoForge.

- [About Sculk Sight](About) — what the mod is and its current status.
- [Installation](Installation) — requirements and the right file for your loader.
- [Troubleshooting](Troubleshooting) — help with installation and launch problems.

For downloads and the complete release notes, see [GitHub Releases](https://github.com/scr0ols/Sculk-Sight/releases).
